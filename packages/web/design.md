# Design — Organización Curini

## Visual Direction
Dark-first dashboard. Inspired by modern SaaS tools: deep navy/charcoal backgrounds, crisp white typography, blue electric accent. 
Professional, dense information layout, no fluff.

## Color Palette (dark theme default)
- Background: `#0a0f1e` (deep navy)
- Surface / card: `#111827` (dark gray-blue)
- Border: `#1f2937`
- Primary accent: `#2563eb` (electric blue)
- Secondary accent: `#3b82f6`
- Text primary: `#f9fafb`
- Text muted: `#9ca3af`
- Success: `#10b981`
- Warning: `#f59e0b`
- Danger: `#ef4444`

## Typography
- Display: `Syne` (bold headers)
- Body: `DM Sans` (clean, legible)
- Mono: `JetBrains Mono` (numbers, codes)

## Layout
- Sidebar navigation (collapsible, 240px)
- Main content area with generous padding
- Stat cards in grid
- Tables with hover states
- Dense but breathable

## Component Style
- Cards: dark background, subtle border, no aggressive shadow
- Buttons: blue primary, ghost secondary
- Badges: colored pills for status
- Tables: alternating subtle rows, sticky header
